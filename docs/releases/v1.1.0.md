# SecHeaders Lab v1.1.0

**Download your report, and more evidence behind every release.** Scores, grades and the API are unchanged.

## Added

- **Download JSON.** The results page has a new "Download JSON" button next to Print. It saves the full result as `secheaders-<host>-<date>.json`, built in your browser: no extra request is made and nothing is stored. Cookie values stay redacted, as on the page.
- **IP policy checked against IANA.** The scanner's list of blocked address ranges is now tested against the official IANA IPv4 and IPv6 special-purpose registries. This found one range, `2001::/23`, that was refused only by the IP library; it is now on the explicit list as well.
- **Test results on every CI run.** Each run now shows its test counts and coverage on the run page.
