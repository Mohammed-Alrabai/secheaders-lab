# SecHeaders Lab v1.0.0

**First public release.** SecHeaders Lab reviews the security of any public website in seconds: HTTP security headers, HTTPS and TLS, cookies and information disclosure. It returns a score, a grade from A+ to F, a plain-language explanation for every finding and a ready-to-copy fix for your server, in English or Arabic.

**Try it:** https://secheaders-lab.netlify.app

## Highlights

- **21 checks, one clear grade.** A published, versioned scoring model with deductions per rule, grade caps for serious gaps (no HTTPS, an invalid certificate, outdated TLS, missing HSTS or CSP) and strict A+ requirements.
- **Fixes you can paste.** Configuration for Nginx, Apache, IIS, Next.js, Netlify and Cloudflare, with MDN and OWASP references for every finding.
- **Reports you can share.** Shareable result links and a print-ready A4 report (Save as PDF) with your platform's fixes only.
- **English and Arabic.** Full right-to-left support, light and dark themes, and WCAG 2.2 AA accessibility.
- **Safe on live sites.** The scan only reads what a site already sends to every visitor: no crawling, no probing and no attack traffic.
- **Private by design.** No accounts, no analytics, no tracking, and scan results are never stored. The Privacy Policy, Terms of Use and Cookie Policy describe exactly what happens.

## Security of the tool itself

A service that fetches user-supplied URLs is a server-side request forgery (SSRF) target, so SecHeaders Lab is built defensively first:

- Strict URL policy, public-address-only DNS validation and connections pinned to the validated IP, which defeats DNS rebinding. Every redirect is re-validated from scratch.
- A hardened API: same-origin requests only, strict schema, small body limit, platform and in-app rate limits, and error messages that never reveal internal details.
- A per-request nonce Content-Security-Policy with `'strict-dynamic'` and a full set of security headers.

The live site scores itself **A+ / 100** and earns **A+ (140/100, 12 of 12 tests) on Mozilla Observatory**.

## Quality

- 1,280 unit and integration tests (about 99.8% statement coverage of the core library), including a 24-case SSRF matrix that runs against local servers with mocked DNS and never touches the internet.
- 75 end-to-end tests covering user flows, error states, printing, keyboard-only use, CSP violations and accessibility (axe) in both languages and both themes.
- Lighthouse on the live site: Performance 99–100, Accessibility 100, Best Practices 100, SEO 100.
- CI on every change: lint, type checks, tests, build, end-to-end tests, dependency audit, CodeQL, Semgrep and Gitleaks, with GitHub Actions pinned to commit SHAs.

## Notes

SecHeaders Lab is a passive review, not a penetration test, and its results are guidance rather than a compliance assessment. Only scan sites you own or are authorized to assess.
