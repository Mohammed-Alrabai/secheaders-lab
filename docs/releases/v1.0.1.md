# SecHeaders Lab v1.0.1

**Security hardening release.** Three fixes from an external review of the repository. Scores, grades and the API are unchanged.

## Fixed

- **No sensitive URL data over plain HTTP.** When a site's HTTPS fails, the scanner falls back to HTTP. It now requests only the site's root (`http://<host>/`), as the design always intended. Previously the submitted path and query, which can carry tokens, were sent unencrypted.
- **No requests to unrelated sites.** The HTTP-to-HTTPS redirect check now stops before any redirect that leaves the scanned site, instead of following it. Tenants of shared hosts such as `github.io` count as different sites.
- **Cleaner error handling.** A request whose body fails or is cancelled while being read now gets a standard `400` error with `no-store`, instead of a generic server error.

Each fix comes with a regression test that failed before the change. The README test counts are also corrected.
